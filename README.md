
# Разработка web-сайта для онлайн записи в автосервисы

**Статус:** В разработке  
**Учебная группа:** К-ИСП-231  
**Учебный год:** 2026–2027

## 1. Описание проекта

Наш проект представляет собой веб-платформу для онлайн-записи в автосервисы, которая объединяет автовладельцев и станции технического обслуживания в едином цифровом пространстве: клиенты получают возможность быстро находить подходящие СТО, знакомиться с ценами, отзывами и услугами, а также записываться на удобное время без звонков, в то время как автосервисы и администраторы получают удобные инструменты для управления расписанием, услугами и загрузкой постов.


## 2. Функциональные возможности

- [ ] Регистрация и авторизация пользователей
